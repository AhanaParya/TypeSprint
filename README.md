
# TypeSprint - Typing Speed Test

TypeSprint is a responsive typing speed test website built with HTML, CSS, and JavaScript.

## Features

- 30-second and 60-second typing tests
- Live typing speed in WPM
- Live accuracy calculation
- Correct and incorrect character highlighting
- Personal best score using LocalStorage
- Responsive design for desktop and mobile
- No external JavaScript libraries required

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Select a test duration and start typing.
